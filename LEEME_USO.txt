MINISUMOS RC — PAQUETE PORTÁTIL PARA WINDOWS

REQUISITOS
- Windows 10 u 11 de 64 bits.
- Para conectar celulares, activa el hotspot móvil de Windows en el PC.
- No necesitas instalar Python en el computador que ejecuta el paquete compilado.

INSTALACIÓN Y USO
1. Descarga MiniSumosRC-Windows-x64.zip desde GitHub Actions (artefacto) o desde Releases.
2. Extrae la carpeta completa MiniSumosRC en una ubicación donde tu usuario pueda escribir, por ejemplo Documentos o el Escritorio. No la ejecutes directamente desde el ZIP ni la instales dentro de Archivos de programa.
3. Activa el hotspot de Windows si quieres conectar celulares.
4. Haz doble clic directamente en MiniSumosRC.exe.
5. Si hace falta configurar el acceso del hotspot, acepta la solicitud de administrador de Windows. El programa deshabilita únicamente reglas de bloqueo que apunten a ese mismo ejecutable y afecten TCP 8000; después crea un permiso limitado a la interfaz y subred del hotspot.
6. El dashboard se abrirá en el navegador del PC en http://127.0.0.1:8000. Para los celulares, usa la IP del hotspot del PC seguida de :8000. El archivo iniciar_ejecutable.bat queda disponible como alternativa.

IMPORTANTE
- Mantén abierta la ventana de MiniSumos RC mientras uses el dashboard.
- Si mueves la carpeta a otra ubicación o cambia la interfaz del hotspot, el lanzador comprobará la regla y volverá a solicitar permiso cuando sea necesario.
- El firewall permanece activado. El instalador no desactiva reglas generales de Python ni el firewall completo.
- El programa no desactiva el firewall completo ni cambia reglas de otros ejecutables. Solo deshabilita reglas de bloqueo de entrada asociadas a la ruta exacta de MiniSumosRC.exe que afecten TCP 8000.
- La base de datos incluida es BasesDeDatos/competencia.db del proyecto MiniSumosRC_HTML. No se consulta la base de datos del proyecto MiniSumosRC de escritorio.
- Para conservar los datos, mantén la carpeta extraída y haz una copia de seguridad de ella antes de reemplazarla por una versión nueva.
- El paquete está pensado para Windows x64. No es un instalador MSI; es una carpeta portátil comprimida.

SI NO ABRE
- Verifica que el hotspot esté activo antes de iniciar.
- Comprueba que TCP 8000 no esté ocupado por otra aplicación.
- No desactives el firewall completo. Conserva el mensaje de error y revisa la regla específica de MiniSumos RC.
